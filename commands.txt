Deploy Container:
    sudo docker compose up -d --build
Stop the container: 
    sudo docker compose down
View running logs: 
    sudo docker compose logs -f
Restart the database: 
    sudo docker compose restart
See print out from python:
    sudo docker logs -t python-environment
Clear mysql config:
    sudo rm -rf /mnt/dietpi_userdata/docker-data/mysql/*
Restart Python app:
    sudo docker compose restart python-app
See print out from web-server:
sudo docker logs html-web-server

Getting GPS to work:
sudo apt update
sudo apt install gpsd gpsd-clients

sudo vi /etc/default/gpsd
edit:
DEVICES="/dev/serial0"
GPSD_OPTIONS="-n -G"
USBAUTO="true"

sudo systemctl restart gpsd

check that it works:
cgps
gpsmon

check address of accelorometer and LCD.
i2cdetect -y 1

Create password:
sudo docker run --rm -it \
  -v "$(pwd)/auth:/auth" \
  --entrypoint htpasswd \
  httpd:alpine \
  -cB /auth/.htpasswd admin
